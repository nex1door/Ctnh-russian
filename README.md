# Русская локализация Create: New Horizon (CTNH)

Полный русский перевод модпака **Create: New Horizon** для Minecraft **1.20.1 (Forge)** —
квестбук, имена предметов и блоков, тултипы, интерфейсы, руководства Patchouli, тексты
обучающих сцен Create, материалы GregTech и аддонов CTNH.

**67 258 строк · 195 namespace · 0 непереведённых игровых строк.**

Ставится как обычный ресурспак: один zip, без правки модов, конфигов и квестов.

Внутри zip — только языковые файлы `assets/<namespace>/lang/ru_ru.json`. Кода модов, текстур
и чужих ресурспаков в архиве нет.

### Что намеренно оставлено латиницей

Это не недоперевод, а соглашение:

- уровни напряжения GregTech: `ULV`, `LV`, `MV`, `HV`, `EV`, `IV`, `LuV`, `ZPM`, `UV`, `UHV`,
  `UEV`, `UIV`, `UXV`, `OpV`, `MAX`;
- названия модов и аббревиатуры: `Create`, `GregTech`, `AE2`, `ME`, `EMI`, `Botania`, `Tetra`;
- единицы и обозначения: `EU`, `FE`, `RF`, `mB`, `SU`, `RPM`, `HPCA`, `SMD`;
- ники, имена собственные и идентификаторы предметов внутри текста.

## Установка

1. Скачайте `CTNH-RU-Language-1.20.1-v1.0.zip` из папки [`release/`](release/) — или со страницы
   Releases, если она есть.
2. Положите архив в папку `resourcepacks` инстанса:
   `.../instances/Create- New Horizon/minecraft/resourcepacks/`
3. Запустите игру → **Настройки → Наборы ресурсов** → включите «Русская локализация Create: New
   Horizon».
4. Поднимите пак **выше** китайского языкового пака и выше пункта «Ресурсы модов»
   (`mod_resources`) — при равном приоритете побеждает тот, что ниже в списке, поэтому наш пак
   должен стоять последним.
5. Язык игры должен быть **Русский (Россия)**.
6. Перезапустите игру. `F3 + T` обычно тоже достаточно, но полный перезапуск надёжнее:
   языковые файлы читаются при загрузке ресурсов.

### Удаление

Удалите zip из `resourcepacks` и выключите его в списке наборов ресурсов. Никаких следов в мире,
конфигах и квестах пак не оставляет.

## Совместимость

- Minecraft **1.20.1**, Forge, `pack_format` **15**.
- Собран под версии модов из модпака **Create: New Horizon** (CTNH-Core 1.4.3a, GregTech Modern
  7.5.0-ctnh, Create 6.0.8 и остальные 230 модов на момент сборки).
- При обновлении пака часть ключей меняется: новые строки будут показываться по-английски или
  сырым ключом, пока пак не обновят. Старые строки при этом не ломаются.
- Другие модпаки: перевод рассчитан на CTNH. Часть строк (Create, Tinkers, AE2, Botania) подойдёт
  и другим сборкам, но квестбук и материалы CTNH будут лишними.

## Структура репозитория

```
assets/<namespace>/lang/ru_ru.json   исходники перевода — один файл на мод
pack.mcmeta                          метаданные ресурспака (pack_format 15)
pack.png                             иконка пака
release/                             собранный zip для игроков
tools/build_pack.py                  сборка zip из assets/ + pack.mcmeta + pack.png
tools/validate_pack.py               проверка архива: JSON, ключи, отсутствие китайского
README.md                            этот файл
LICENSE                              CC BY-NC-SA 4.0
CHANGELOG.md                         история версий
```

Перевод лежит именно исходниками, а не только собранным архивом: так правки можно присылать
пул-реквестом в конкретный файл, а не присылать заново весь zip.

## Сборка

Нужен только Python 3 (стандартная библиотека).

```bash
python3 tools/build_pack.py            # соберёт release/CTNH-RU-Language-1.20.1-v1.0.zip
python3 tools/validate_pack.py        # проверит собранный архив
```

`build_pack.py` собирает zip детерминированно (фиксированные даты записей), поэтому повторная
сборка без изменений даёт побайтно тот же файл — удобно для diff'ов и CI.

`validate_pack.py` проверяет: каждый файл — валидный JSON; нет китайских иероглифов в значениях;
ключи непустые; `pack.mcmeta` на месте и с `pack_format` 15. Он же печатает сводку по строкам.

## Как обновлять под новую версию пака

1. Запустите игру с паком и найдите строки, которые показываются сырым ключом
   (`material.ctnhcore.foo (слиток)`) или по-английски.
2. Найдите ключ в jar'ах модов:

   ```bash
   for j in mods/*.jar; do unzip -p "$j" assets/*/lang/en_us.json 2>/dev/null | grep -l "ключ"; done
   ```

   или просто `grep -r "ключ" assets/ mods/ kubejs/`.
3. Добавьте пару `"ключ": "перевод"` в `assets/<namespace>/lang/ru_ru.json`, пересоберите пак.

Для массового обновления удобнее сравнить набор ключей мода с нашим файлом:

```python
import json, zipfile
jar = zipfile.ZipFile("mods/create-1.20.1-6.0.8.jar")
src = json.loads(jar.read("assets/create/lang/en_us.json"))
ours = json.load(open("assets/create/lang/ru_ru.json"))
print(sorted(set(src) - set(ours)))      # что появилось нового
```

## Как предложить правку

Присылайте пул-реквест с изменённым `assets/<namespace>/lang/ru_ru.json`. Пожалуйста:

- **не меняйте ключи** — только значения;
- сохраняйте форматирование: коды `§0`–`§f`, `§k`–`§o`, `§r`, `%s`, `%d`, `%1$s`, `%%`,
  `\n` должны остаться на своих местах и в том же количестве (иначе игра покажет пустоту
  или упадёт при подстановке аргументов);
- придерживайтесь терминологии из перевода: `стресс` (stress), `вал` (shaft), `редуктор`
  (gearbox), `энергетический люк` (energy hatch), `входная/выходная шина` (input/output bus),
  `кровавый алтарь`, `воля демона`, `мана`, `манасталь`, `терасталь`, `кварц Сертус`;
- названия предметов и блоков — со строчной буквы и без точки в конце; подсказки и интерфейс —
  с заглавной и точкой;
- уровни напряжения — только латиницей.

Перед PR прогоните `python3 tools/validate_pack.py` — он ловит битый JSON и потерянные
плейсхолдеры.

## Известные ограничения

- **Версии должны совпадать.** Пак собран под конкретный набор версий модов; после обновления
  пака возможны новые непереведённые строки.
- **Часть терминов — выбор переводчика.** Там, где у мода нет официального русского названия
  (CTNH-Mana, CTPP, часть материалов GregTech), термин выбран и закреплён за предметом
  последовательно по всему паку, но может отличаться от того, к чему вы привыкли.
- **Машинные строки конфигов** переведены по смыслу опции, а не дословно: в интерфейсе они
  читаются как подписи, а не как техническая документация.
